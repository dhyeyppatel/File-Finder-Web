# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- **Search History**: Displays last 5 search terms when focusing the empty search bar.
- **Copy Link**: Button to quickly copy the Telegram file link to clipboard.
- **Dynamic Stats**: Real-time total file count displayed in the search placeholder (e.g., "Search 500,000+ files...").
- **Keyboard Shortcut**: Press `/` to focus the search bar instantly.
- **Theme System**: Dynamic theme switching (Violet, Emerald, Amber, Rose, Sky) with persistent storage.
- **Sidebar**: Revamped sidebar with "Features", "How to use", and integrated Theme Picker.
- **Zero-State**: Enhanced "No results" message with helpful tips.

### Changed
- **UI Overhaul**: Complete Glassmorphism redesign with blur effects, vibrant gradients, and Inter font.
- **Dark Mode**: Fixed toggle visibility and improved color contrast for dark theme.
- **Performance**: Optimized search results rendering and added debounce for typing.

### Fixed
- **Mobile Responsiveness**: Improved sidebar touch interactions and overlay handling.
